Settings that only affect the built-in Nyaa search. Torznab / newznab indexers ignore these because they have no equivalent on the wire.

When set, every Nyaa search is scoped to ?u=<name> so only this uploader's releases come back. Tighter and faster than a title-contains group filter. Must match an actual Nyaa account; groups without a dedicated uploader return zero results. Per-series overrides on the series page beat this default.
