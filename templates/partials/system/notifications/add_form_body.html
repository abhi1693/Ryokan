{# Modal body for the Add flow. Returned by `GET /system/notifications/add-form` and also rendered server-side on initial section render so the modal opens fast on first click without waiting for a fetch. The HTMX target on the click handlers is `#notif-modal-body innerHTML`, so this is the entire content of that div (no header, no backdrop). Default kind is webhook (matches the dropdown's `selected` option); the discord field group is hidden initially. The kind-flip JS in static/js/settings.js (or wherever the notif modal helpers land) toggles visibility live when the user changes the kind dropdown. #}
{# Webhook field group — visible by default. The kind-flip JS toggles `display: none` on this and the discord group as a pair. #}
Any HTTPS receiver that accepts POST + JSON. Examples: ntfy, Apprise, n8n, custom scripts.
If set, every send carries an X-Ryokan-Signature: sha256=<hex> header (HMAC over the raw body bytes). Receivers can use off-the-shelf GitHub-style verification code.
One per line, Header-Name: value. Blank lines and # comments allowed. Reserved names (Content-Type, X-Ryokan-Signature) are rejected at save.
