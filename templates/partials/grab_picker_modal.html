{# Interactive file-picker modal (issue #83). Opened by openGrabPicker() in grab_picker.js when the user hits Grab on a batch release. Single-file releases bypass this and take the direct grab path. Footer + toolbar start hidden — they flip to flex once the file list is rendered. Included verbatim by any page whose Grab buttons can route through the picker (search.html, series.html). Include at most once per page — every interactive element below uses a hardcoded global ID (`grab-picker-modal`, `grab-picker-title`, `grab-picker-confirm`, etc.) that grab_picker.js binds to via `document.getElementById`. A second include on the same page would produce duplicate IDs and the JS would silently target the first one only. #}
