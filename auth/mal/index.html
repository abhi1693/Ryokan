Ryokan — MyAnimeList Authorization

MyAnimeList has issued an authorization code for Ryokan. Copy both the code and the state value below, then paste them into your Ryokan instance under Settings → Integrations → External Accounts.

The code is single-use and expires in a few minutes. The state value is a one-time CSRF nonce that proves this approval is the same one your Ryokan started; without it Ryokan will reject the link. If Ryokan rejects either, come back and link again.
